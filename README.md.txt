# ❤️ HeartHive – AI Powered Medical RAG Chatbot

## 📌 Overview
HeartHive is an AI-powered medical chatbot focused on cardiovascular health.  
It uses the BioMistral Large Language Model (LLM) with Retrieval-Augmented Generation (RAG) to provide accurate, context-based medical responses.

The system retrieves information from a validated heart health PDF knowledge base and generates reliable answers for users.

---

## 🚀 Features
- 💬 Natural language medical query handling
- 📄 PDF-based knowledge retrieval
- 🧠 BioMistral LLM integration
- 🔎 Retrieval-Augmented Generation (RAG)
- ❤️ Focused on Heart Health awareness

---

## 🛠️ Tech Stack
- Python
- Hugging Face Transformers
- BioMistral LLM
- RAG Framework
- Jupyter Notebook
